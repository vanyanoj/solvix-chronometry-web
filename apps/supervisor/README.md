# Solvix Chronometry — фронт старшего смены

React + TypeScript + Vite + Tailwind (настроен под shadcn/ui).
Светлая тема, зелёный акцент, Manrope — дизайн-система Solvix Chronometry.

## Запуск

```bash
cd apps/supervisor
npm install
npm run dev
```

Откроется на <http://localhost:5173>. Запросы `/api` и WebSocket проксируются
на бэкенд — адрес задаётся в `vite.config.ts` (по умолчанию
`http://localhost:8000`).

**Бэк на другой машине?** Поменяй `target` в `vite.config.ts` на адрес ноутбука
в локальной сети, например `http://192.168.0.42:8000`.

## Авторизация

Вход старшего — `POST /api/v1/auth/login`, поле `pass_code`. Бэк принимает
туда **и код пропуска, и UID именного NFC-бейджа** (одно поле, без логина).

- **Основной путь** — именной бейдж. Чтобы он заработал, UID бейджа старшего
  должен быть записан как его код доступа (сидом или через `pass_code_hash`).
- **Запасной путь** — ручной ввод кода: ссылка «Войти по коду» под карточкой.
  Нужен, если бейдж забыт или ридер неисправен.

Токен (12 ч) хранится в `sessionStorage`, при 401 сессия сбрасывается и
пользователь возвращается на экран входа.

Пока физического ридера нет, **клик по зоне считывания** отправляет тестовый
UID `04A3F7B9` (см. `TODO(nfc)` в `useNfcAuth.ts`).

## Экран «Назначения»

Три шага: сотрудник → бейдж и станок → подтверждение. Всё на реальных данных:

- `GET /users?role=operator&active=true` — список операторов
- `GET /badges?status=free` — свободные бейджи
- `GET /dashboard/stations` — станки и кто на них сейчас
- `POST /shifts` — создание смены

Занятые операторы и станки заблокированы. Ошибка 409 (кого-то успели занять
параллельно) показывается сообщением, и данные перечитываются.

## Структура

```
src/
├── api/
│   ├── types.ts        TS-типы, снятые 1:1 с Pydantic-схем бэка
│   ├── client.ts       HTTP-клиент: JWT, разбор ошибок FastAPI
│   └── AuthContext.tsx текущий пользователь, вход/выход
├── components/
│   ├── brand/Logo.tsx  значок + вордмарк Solvix
│   └── layout/         Sidebar (6 пунктов меню) + AppLayout + PageHeader
├── screens/
│   ├── auth/           экран входа + state-machine считывателя
│   └── assignments/    экран «Назначения»
├── lib/utils.ts        cn() (clsx + tailwind-merge)
└── index.css           дизайн-токены
```
